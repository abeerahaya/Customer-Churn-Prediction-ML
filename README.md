Customer Churn Prediction Using Machine Learning

## 📌 Project Overview

Customer churn prediction is a Machine Learning project that predicts whether a customer is likely to leave a service or continue using it.

The goal of this project is to identify customers at risk of churn by analyzing customer information and building an accurate classification model.

This project follows a complete Machine Learning workflow:

- Data Understanding
- Exploratory Data Analysis (EDA)
- Data Cleaning
- Data Preprocessing
- Feature Engineering
- Model Training
- Model Evaluation
- Prediction


## 🎯 Objective

The main objective is to develop a machine learning model that can accurately predict customer churn and help businesses improve customer retention strategies.


## 📂 Dataset

Dataset contains customer-related information such as:

- Customer demographics
- Account information
- Service details
- Monthly charges
- Contract type
- Payment method
- Tenure
- Churn status
